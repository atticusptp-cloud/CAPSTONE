# Hotel Booking Cancellation & Revenue Analytics

Written using only the techniques covered in the PCEP and PCED learner guides.

| File | What it is |
|---|---|
| `Hotel_Booking_Analysis.ipynb` | Main notebook, all outputs saved |
| `Hotel_Booking_Analysis.html` | The same notebook as a web page |
| `Hotel_Booking_Dashboard.html` | Interactive plotly dashboard (exported from the notebook) |
| `data/raw/` | The 5 original CSV tables + data dictionary |
| `data/processed/hotel_bookings_clean.csv` | Cleaned and joined dataset (118,561 rows) |
| `data/processed/model_results.csv` | Linear regression model comparison |

## How to run
pip install -r requirements.txt, then open the notebook in Jupyter and choose Kernel -> Restart & Run All (takes under a minute).
Keep the `data` folder next to the notebook.
